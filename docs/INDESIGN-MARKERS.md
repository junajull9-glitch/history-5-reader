# Метки, экспортируемые из InDesign

## Оглавление
Добавляйте к экспортируемому элементу заголовка атрибут:

    data-toc-title="Название пункта"

Дополнительно можно использовать `data-toc-level="1|2|3"`.

## Печатная страница
В начале каждой печатной страницы размещайте невидимый элемент:

    <span class="print-page-marker" data-print-page="24"></span>

Читалка показывает и ищет именно этот номер, а не номер экранного разворота.
