# Book bridge

`app/book-bridge.js` формирует только одностраничную электронную пагинацию.

Модуль отвечает за:
- разбиение потока книги на экранные страницы;
- переходы по номеру экранной страницы и оглавлению;
- поиск;
- изменение размера шрифта;
- заметки, закладки и просмотр изображений.

Номера бумажного издания и маркеры исходной вёрстки не используются.
