# Интерактивные модули

Каждый модуль хранится в отдельной подпапке:

modules/<module-id>/index.html
modules/<module-id>/module.json
modules/<module-id>/assets/...

В тексте учебника точка запуска обозначается так:

<button data-module="module-id">Открыть модуль</button>

Подключение обработчика модулей вынесено отдельно и может дорабатываться без изменения книги.
